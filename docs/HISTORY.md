# היסטוריית הפיתוח / Development history

סיכום של כל הבקשות מהשיחה עם Claude (אוקטובר 2026) ומה נבנה בעקבותיהן, לפי הסדר.
Summary of every request from the original Claude conversation and what was built, in order.

## 1. הבסיס / Foundation
1. אפליקציה חיה לשליחים ושולחים במנגנון מאצ': שליח מחליק ימינה/שמאלה על בקשות משלוח; שולח (פרטי/עסק) מפרסם משלוח ומחליק על שליחים באזור לפי סוג רכב; מאצ' הדדי פותח צ'אט.
2. שני ממשקי בדיקה מחוברים: `#testcourier` ו־`#testsender` — **חייבים להישאר קבועים בכל שינוי עתידי.**
3. עיצוב UX/UI מחדש: פשוט, זורם, כיפי, נגיש וברור.
4. מצב בהיר/כהה; כפתור פרטים קטן יותר בצ'אט.
5. שליחת מיקום בצ'אט בלחיצה (בקשת הרשאה). ב־Claude ה־GPS חסום → נפילה לכתובת + קישורי מפה, בכנות.
6. כפתור + בצ'אט: מיקום, צילום/גלריה, הקלטה קולית, תשלום.
7. אמצעי תשלום: מזומן, אשראי, ביט, פייבוקס (ובהמשך העברה בנקאית/PayPal לפי מדינה).
8. ניקוי משלוחים שהסתיימו.
9. סיור הדרכה אינטראקטיבי אחרי יצירת פרופיל.
10. מסך הכרטיסים קומפקטי — כפתורי לקחת/דלג תמיד גלויים; צד הכפתור תואם לכיוון ההחלקה.
11. בדיקות מקיפות ותיקון באגים.
12. ארכיון/מחיקת צ'אט עם תפריט ⋯ והחלקה (ימינה = מחיקה, שמאלה = ארכיון). מחיקה רק לצ'אט סגור.
13. ריבוי שפות: עברית / English / Русский / العربية עם כפתור שפה.
14. "המשלוחים שלי" לשליח עם עדכוני סטטוס חיים (יצאתי, נאסף, הגעתי, נמסר); השולח רואה בזמן אמת + התראות; התראות על הודעות צ'אט לשני הצדדים.
15. גלובלי: בחירת מדינה (מטבע, אמצעי תשלום, ערים).
16. מסך התחברות/הרשמה (אימייל, שם משתמש, סיסמה, אימות); אימות אימייל **מדומה** עם "תיבת דואר לדוגמה"; זכור אותי; נשאר מחובר עד יציאה; מסך הגדרות; איפוס בדיקה מחזיר למסך ההתחברות ומשתמשי בדיקה קיימים עדיין נכנסים.

## 2. עשרת הרעיונות / The 10 features
1. מחיר מוצע (גודל, רכב, דחיפות, מרחק, מדינה, היסטוריה).
2. דירוגים וביקורות לשני הצדדים.
3. הוכחת מסירה — צילום או חתימה.
4. קוד מסירה חד־פעמי (4 ספרות, נעילה אחרי 5 טעויות, אישור ידני).
5. מסלול חכם לכמה משלוחים (Google Maps / Waze).
6. משלוחים קבועים לעסקים + שליח קבוע.
7. זמן הגעה משוער (במקום מפה חיה — לא אפשרי ב־Claude).
8. אימות זהות לשליחים + ניהול ע"י בעל האפליקציה + סינון "רק מאומתים".
9. ארנק לשליח — יומן הכנסות (בלי נאמנות/העברת כסף אמיתית), CSV.
10. לוח בקרה לעסק — סטטיסטיקות, הוצאות חודשיות, שליחים מועדפים, CSV.

## 3. QA, עומסים, נגישות ועיצוב
- בדיקת עומסים: 700 שליחים, 300 שולחים, 3,000 משלוחים, ~5,300 מאצ'ים — מסכים ב־5–30ms.
- תוקן: מסמך משתמש שעובר 256KB הכניס את האפליקציה ל"קריאה בלבד" → כיווץ אוטומטי + ניסיון חוזר.
- ממואיזציה של חישובי מאצ'ים והתראות (פי 5–10 מהר יותר).
- נגישות: ניגודיות, מלכודת פוקוס בחלונות + החזרת פוקוס, כותרות, יעדי מגע.
- עיצוב: פס בדיקה בשורה אחת, הודעות קופצות למעלה, לשונית "פנויים" לשליח, ועוד.

## Next steps that need a real backend
- Per-chat privacy (ACL), real payments/escrow, push notifications, live maps/GPS, >1,000 users.
